# Brother DCP-T420W 맥 사용 안내

[English](README.md) · [자세한 기술 안내](TECHY_README.KO.md) · [다운로드](https://github.com/hwisu/DCP-T420W/releases)

**Brother DCP-T420W를 맥의 기본 인쇄 메뉴에서 사용**하게 해주는 커뮤니티 드라이버입니다.
미리보기·Safari 등에서 바로 인쇄할 수 있고, 터미널용 스캔 도구 `brscan`도 포함합니다.
Brother의 공식 제품은 아닙니다.

## 1. 설치하기

1. 프린터를 켜고 맥과 같은 네트워크에 연결합니다.
2. [Releases](https://github.com/hwisu/DCP-T420W/releases)에서 `.pkg` 설치 파일을 받습니다.
3. 파일을 열어 설치합니다. **iPhone·iPad 프린터 공유**는 필요한 경우에만 선택하고,
   먼저 아래 보안 안내를 읽어주세요.
4. 문서를 열고 **⌘P**를 누른 뒤 **Brother DCP-T420W**를 선택합니다.

설치 중 프린터를 찾지 못했다면 **시스템 설정 → 프린터 및 스캐너**에서 추가하고,
드라이버로 **Brother DCP-T420W (PWG Raster)**를 선택하세요.

**설치 전 보안 안내**

- 설치 파일은 **개발자 서명이 없는 파일**입니다. macOS에서 개발자를 확인할 수 없다며
  차단할 수 있습니다. 이 저장소의 Releases에서만 받고, 프로젝트를 신뢰할 때 설치하세요.
  Gatekeeper를 시스템 전체에서 끄지 마세요. 차단될 때의 설치 방법은
  [기술 안내](TECHY_README.KO.md#설치와-업그레이드)에 있습니다.
- 프린터 공유는 **기본적으로 꺼져 있습니다.** 켜면 같은 로컬 네트워크의 누구나
  **비밀번호 없이 인쇄**할 수 있으므로 신뢰하는 네트워크에서만 사용하세요.
- 노트북이 다른 Wi-Fi에 연결되어도 공유 설정은 유지됩니다. 공공·공용 Wi-Fi를
  이용하기 전 공유를 끄세요. 공유 포트를 인터넷으로 연결하는 포트 포워딩도 하지 마세요.
- 예전에 켠 공유 설정은 업그레이드 후에도 유지될 수 있습니다.
  [공유 끄는 방법](TECHY_README.KO.md#공유와-보안)을 확인하세요.

## 2. 인쇄하기

일반 문서는 **A4 · 일반 용지 · 표준 문서** 품질을 사용하면 됩니다.

| 하고 싶은 작업 | 인쇄 창에서 찾는 위치 |
|---|---|
| 컬러·흑백, 품질, 용지 종류 변경 | **프린터 옵션 → 프린터 기능** |
| 홀수 또는 짝수 페이지만 인쇄 | **용지 프린트 방식 → 프린트할 시트** |
| 첫 페이지부터 인쇄 | **용지 프린트 방식 → 시트 순서 → 정순** |
| 마지막 페이지부터 인쇄 | **용지 프린트 방식 → 시트 순서 → 역순** |

**1.4.0 변경 사항:** 시트 순서가 ‘자동’이면 **마지막 페이지부터 인쇄**합니다.
업그레이드 후 이전 순서가 필요하면 ‘정순’을 선택하세요. 기존 프리셋에 저장한
페이지 순서가 기본값보다 우선할 수 있습니다.

매번 세부 메뉴를 열기 번거롭다면 아래 조합을 **프리셋 → 현재 설정을 프리셋으로 저장**에서
저장하세요. 사용 가능한 프린터는 이 Brother 프린터만 선택하면 됩니다.

| 추천 프리셋 이름 | 색상 | 품질 | 용지 |
|---|---|---|---|
| 컬러 문서 · A4 | 컬러 | 표준 문서 | A4, 일반 용지 |
| 흑백 문서 · A4 | 흑백 | 표준 문서 | A4, 일반 용지 |
| 잉크 절약 · 흑백 A4 | 흑백 | 에코 | A4, 일반 용지 |

이 프리셋은 설치 프로그램이 자동으로 추가하는 항목이 아니라 사용자가 저장하는 설정입니다.
저장 전 시트 순서·크기 조절·매 수도 확인하세요. 이 프린터에는 자동 양면 인쇄 기능이 없으며,
여백 없는 인쇄에는 인화지를 사용해야 합니다.

## 3. 스캔하기

**맥 기본 앱을 쓰고 싶다면 ‘이미지 캡처’를 사용하세요.** Brother는 DCP-T420W에
별도의 **스캐너 드라이버(ICA)**를 설치하여 이미지 캡처로 스캔하는 방법을 안내합니다.
[Brother 다운로드 페이지](https://support.brother.com/g/b/downloadtop.aspx?c=eu_ot&lang=en&prod=dcpt420w_all)에서
사용 중인 macOS를 선택하고 ICA 드라이버가 제공되는지 확인하세요.
설치 후 **이미지 캡처 → Brother 스캐너 선택 → 세부사항 보기**에서 PDF·이미지 형식,
저장 위치 등을 설정합니다.

이 프로젝트의 설치 파일에는 ICA 드라이버가 **포함되지 않습니다.** 인쇄가 된다고 해서
이미지 캡처에도 자동으로 스캐너가 나타나는 것은 아닙니다.
[Brother의 이미지 캡처 사용 안내](https://support.brother.com/g/s/id/htmldoc/mfc/cv_dcp220/mexlte/html/GUID-6A4819EC-1724-4DEE-ABA5-BC35B08593A0_70.html)도 참고하세요.

포함된 터미널 도구를 쓰려면 원고를 유리판에 놓고 다음을 실행합니다.

```sh
brscan --out ~/Desktop/scan.pdf
```

자동 급지 장치가 없어 한 번에 한 장씩 스캔합니다. `brscan`은 색상·자르기·회전을 맥에서
처리하며, DPI를 높게 요청해도 실제 스캔 해상도가 높아지지는 않습니다.

## iPhone·iPad에서 인쇄하기

신뢰하는 네트워크에서만 설치 프로그램의 공유 옵션을 켭니다. 맥을 켜 둔 상태에서
휴대폰의 **Brother DCP-T420W (AirPrint)**를 선택하면 맥을 거쳐 인쇄됩니다.
이 프로젝트에는 휴대폰 스캔 기능이 포함되지 않습니다.

## macOS 호환성

설치 파일에는 Apple Silicon·Intel용 실행 파일이 함께 들어 있으며 macOS 11 이상을
대상으로 빌드합니다. 모든 OS에서 테스트했다는 뜻은 아닙니다.
처음 개발·테스트한 환경은 macOS 26.5의 Apple Silicon 맥입니다.

다음 환경에서는 사용자가 **v1.3.4 정상 작동을 확인**해 주었습니다.

- **Golden Gate 27.0.1 (26A434)**
- **Tahoe 26.7.1 (25G241)**

이는 v1.3.4에 관한 사용자 보고이며, v1.4.0이나 별도의 Brother ICA 드라이버에 대한
호환성 검증을 의미하지는 않습니다.

## 잘 안 될 때

- **프린터가 안 보여요:** 전원과 네트워크를 확인한 뒤 위 방법으로 프린터를 추가하세요.
- **업그레이드했는데 옛 메뉴가 보여요:** 인쇄하는 앱을 완전히 종료했다가 다시 여세요.
- **페이지 순서가 달라요:** ‘시트 순서’와 선택한 프리셋을 확인하세요.
- **이미지 캡처에 스캐너가 없어요:** ICA 드라이버와 네트워크를 확인하세요.
  이 인쇄 드라이버만 설치해서는 충분하지 않습니다.
- **도움이 필요해요:** macOS 버전, 드라이버 버전, 오류 내용을 적어
  [이슈](https://github.com/hwisu/DCP-T420W/issues)를 등록하세요. 문서 내용·네트워크 주소·개인정보가
  첨부 파일에 노출되지 않도록 확인하세요.

설치 제거, 업데이트 내역, 빌드, 진단 및 기기 제약은 [TECHY_README.KO.md](TECHY_README.KO.md)에 있습니다.
